# Hazel's Portfolio

Live site: https://hazelantonetteapidos-pixel.github.io/

## Projects update themselves
Every time you upload (create) a **public repository** on GitHub, it shows up in the
Projects section the next time someone opens the site. No code changes needed.

- Settings live at the top of `script.js` (`GITHUB_USER`, `HIDDEN_REPOS`).
- To hide a repo, add its name to `HIDDEN_REPOS`.
- To make a repo's card nicer, add a `description` and `topics` on its GitHub page.
- Ideas you have not built yet go in `projects.json` (shown after the real repos).
- To give a repo a custom card, add an entry to `projects.json` with
  `"repo": "your-repo-name"` plus your own `title`, `description`, `technologies`, `demo`.
